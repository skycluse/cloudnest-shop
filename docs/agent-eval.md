## 五、说明与局限

1. **理解自然语言用的是本地规则引擎，不是大模型**。
   所以上面 100% 的完成率只代表"这些用例覆盖到的说法"能被正确处理，
   不代表任意说法都能理解 —— 例如用中文数字说"五百以内"就可能识别不到。
2. **没有做双模型对比**（9.8 第 4 条是可选加分项）。
   因为当前实现没有接入 Qwen / DeepSeek 的 API Key，强行对比没有意义。
   接上模型后，这个脚本可以直接复用：把 `agent.send()` 换成模型请求即可。
3. **幻觉的定义**：推荐给用户的商品 id 不在本轮工具返回的结果里，记为 1 次。
   因为所有商品都来自 `searchProducts` / `getProduct`，这个指标能抓到"凭空编商品"的问题。
